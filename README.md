# 🎉 KIKA PRESTIGE - Site Événementiel Premium

Site web moderne et élégant pour l'agence événementielle KIKA Prestige, spécialisée dans l'organisation d'événements haut de gamme.

## 📋 Fonctionnalités

✨ **Design Premium**
- Interface moderne et épurée
- Thème sombre élégant avec accents dorés
- Animations fluides et transitions douces
- Design responsive (mobile, tablette, desktop)

🎯 **Sections Principales**
- **Header** : Navigation fixe avec menu mobile
- **Hero** : Section d'accroche impactante avec CTA
- **Services** : 4 prestations principales avec icônes
- **Galerie** : Portfolio d'événements avec modal lightbox
- **À propos** : Présentation de l'agence avec statistiques
- **Contact** : Formulaire complet et informations de contact
- **Footer** : Navigation rapide et réseaux sociaux

## 🛠️ Stack Technologique

- **React 18** : Framework JavaScript
- **Tailwind CSS** : Styling utility-first
- **Vite** : Build tool et dev server
- **Lucide Icons** : Icônes modernes

## 📦 Installation

```bash
# Cloner le repository
git clone https://github.com/Maxim903/kika-prestige.git
cd kika-prestige

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build pour la production
npm run build
```

## 🚀 Démarrage

1. Les dépendances sont automatiquement installées
2. Le serveur de développement se lance sur `http://localhost:3000`
3. Hot reload activé - les modifications sont instantanées
